# API Endpoints

Base URL: `http://localhost:5000`

## Health
- `GET /health`

## Authentication
- `POST /auth/register`
- `POST /auth/login`

## Customers
- `GET /customers`
- `POST /customers`

## Rooms
- `GET /rooms`
- `POST /rooms/quick-seed`

## Reservations
- `GET /reservations`
- `POST /reservations`
- `PATCH /reservations/:id/status`

## Complaints
- `GET /complaints`
- `POST /complaints`

## Campaigns
- `GET /campaigns`
- `POST /campaigns`

## Loyalty
- `POST /loyalty/transactions`

## Dashboard
- `GET /dashboard/kpis`
