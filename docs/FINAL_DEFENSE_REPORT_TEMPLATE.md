# Final Year Defense Report Template

Use this structure to prepare your final PDF report.

## Cover Page

- University name
- Department and program
- Project title: **Customer Relationship Management Information System**
- Case study: **The Manor Hotel**
- Student name and registration number
- Supervisor name
- Date

## Abstract

Briefly summarize:

- Problem
- Objective
- Method
- Tools/stack
- Key result

## Chapter 1: Introduction

- Background
- Problem statement
- Objectives (general and specific)
- Scope and limitations
- Significance of the project

## Chapter 2: Literature Review

- CRM concepts
- Hotel CRM best practices
- Related systems
- Identified research gap

## Chapter 3: Methodology and Analysis

- Requirements gathering approach
- Functional requirements
- Non-functional requirements
- Existing system analysis
- Proposed solution approach

## Chapter 4: System Design

- System architecture (use `docs/ARCHITECTURE.md`)
- Use case overview
- Database design summary
- Security design (authentication, roles)

## Chapter 5: Implementation

- Tools and technologies used
- Backend implementation summary
- Frontend implementation summary
- Database implementation and seed data

## Chapter 6: Testing and Results

- Test strategy
- API tests (Postman collection)
- Functional test results
- KPI dashboard results
- User acceptance notes

## Chapter 7: Conclusion and Recommendations

- Achievements vs objectives
- Lessons learned
- Future improvements

## References

Use your required citation style (APA/IEEE/Harvard).

## Appendices

- Appendix A: API endpoint list (`docs/API.md`)
- Appendix B: Screenshot evidence (`docs/screenshots/`)
- Appendix C: GitHub repository link
- Appendix D: Sample SQL seed excerpt

## PDF Export Checklist

- Keep consistent headings and page numbers
- Include all diagrams and screenshots clearly
- Add captions to every figure/table
- Ensure no placeholder text remains
- Export as `The_Manor_Hotel_CRM_Final_Report.pdf`
